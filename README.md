## 2026-06-22

### SIGNATE Cloud - 食品ロス予測（機械学習基礎）

重回帰モデルを用いた予測の流れを学習。

学習内容

* One-Hot Encoding（ダミー変数化）
* train / test データの分割
* 説明変数（X）と目的変数（y）
* LinearRegression による学習
* predict() による予測
* RMSE による評価
* 回帰係数の確認

気付き

* 回帰係数は「その特徴量が1増えたときに予測値がどれだけ変化するか」を表している
* 重回帰モデルは「y = ax + b」の a が複数ある形と考えると理解しやすい
* train_X、train_y で学習し、test_X で予測、test_y で評価する流れを再確認した
* モデル作成自体は数行で終わるが、前処理や特徴量作成の方が圧倒的に時間を使う

反省

後半は前の問題やヒントを見ながら進める場面が増えた。
特に train/test や RMSE の扱いはまだ理解が曖昧な部分があるため、復習が必要。
