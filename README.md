## 2026-07-12

### SIGNATE Quest「DeepLearning入門〜画像分類編〜」完走

今日は、SIGNATE Questの  
「DeepLearning入門〜画像分類編〜」を最後まで完走した。

最初は、画像を読み込むところから開始した。

`skimage.io.imread()` で画像を読み込み、  
画像がNumPy配列として扱われることを確認した。

`shape` を使って、画像の高さ・幅・RGBの3チャンネルを確認した。

`matplotlib` を使って、画像を表示したり、  
複数の画像を並べて確認したりした。

`glob` を使って複数画像のファイル名を取得し、  
for文で1枚ずつ読み込んだ。

10枚の画像をNumPy配列に変換すると、  
`(10, 96, 96, 3)` という形状になった。

画像の画素値を255で割り、  
0〜1の範囲に正規化した。

ファイル名からラベル名を取り出し、  
one-hot encodingで正解ラベルを作成した。

画像とラベルを、訓練用と検証用に分割した。

その後、Kerasを使ってニューラルネットワークを定義した。

Dense層、活性化関数、Softmaxなどの役割を学んだ。

CNNでは、Conv2D、MaxPooling2D、Flattenを使った。

畳み込み層で特徴を抽出し、  
プーリング層で情報を圧縮する流れを確認した。

モデルを定義した後、`model.summary()` で構造を確認した。

`model.compile()` で損失関数とオプティマイザーを設定した。

`model.fit()` を使って、実際にCNNを学習させた。

学習曲線から、accuracy、val_accuracy、loss、val_lossを確認した。

エポック数、層の数、活性化関数、学習率、  
オプティマイザーを変更すると結果が変わることも体験した。

訓練精度だけが上がり、検証精度が伸びない場合は、  
過学習の可能性があることも学んだ。

まだ畳み込みの細かい計算や、  
最適なモデル設計までは十分に理解できていない。

それでも、画像の準備からCNNの学習・評価まで、  
画像分類の一連の流れを最後まで通せた。

細部はこれから復習が必要だが、  
まず1つのGymを完走できたことを成果として残しておく。
